# NETWORKWALKS-B084-WK1-PM1-CYBERSECURITY-SOC-PROJECT--WIRESHARK
Project Overview
As part of my cybersecurity learning journey and internship at NetworkWalks, I completed a series of Wireshark SOC Labs focused on network traffic analysis, threat detection, and security investigation.
## Project Evidence

![Lab 4 Result](https://github.com/janetijeomannaemeka/Cybersecurity-capstone-project/blob/main/Lab%204%20Result%20-%20Janet%20Nnaemeka(1).png?raw=true) 

Using Wireshark, I analyzed network packet captures to investigate suspicious activities, identify potential security threats, examine communication protocols, and understand how attackers exploit weaknesses in network services.
The hands-on exercises covered attacker IP identification, TCP connection analysis, TCP stream inspection, hidden data detection, HTTP authentication, brute-force attack investigation, and VoIP traffic analysis.
Project Objectives
* Analyze network traffic and understand packet-level communication.
* Identify suspicious IP addresses and investigate potential port-scanning activities.
* Examine TCP connections, ports, and packet flags.
* Follow TCP streams to investigate conversations and identify exposed information.
* Analyze HTTP requests and authentication methods.
* Investigate repeated login attempts and identify brute-force attacks.
* Examine VoIP signalling and voice traffic protocols.
* Recommend security measures to protect sensitive network communications.
Tools and Technologies
* Wireshark – Network protocol analysis and packet inspection.
* TCP/IP – Network communication and connection analysis.
* HTTP/FTP – Web traffic and authentication analysis.
* SIP/RTP – VoIP signalling and voice traffic analysis.
* Network Security Monitoring – Identifying suspicious traffic patterns and potential threats.
Key Skills Developed
* Network traffic analysis and packet inspection.
* Threat detection and basic incident investigation.
* TCP connection and port analysis.
* Network reconnaissance and port-scan identification.
* Investigation of brute-force login attempts.
* Protocol analysis and identification of security weaknesses.
* Understanding plaintext data exposure and communication security.
* Security recommendations and incident reporting.
Key Learning Outcomes
These practical labs strengthened my understanding of how network traffic can reveal suspicious activities and potential security vulnerabilities. I gained hands-on experience examining packets, interpreting communication protocols, identifying attack patterns, and understanding the importance of encryption, secure authentication, and continuous network monitoring.
This experience has further strengthened my interest in cybersecurity, particularly Security Operations Centre (SOC) analysis, threat detection, and incident response.
